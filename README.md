# Personal Finance Management Application

## Objective

This application helps users manage their personal finances by tracking income, expenses, budgets, and generating financial reports.

---

## Requirements

* Python 3.x
* SQLite (built-in with Python)

---

## Installation

1. Download or copy the project folder.
2. Open terminal in the project directory.
3. Run the application:

```
python main.py
```

---

## Features

### 1. User Registration

Users can create a new account with username and password.

### 2. User Login

Users can log in using their registered credentials.

### 3. Income and Expense Tracking

Users can add, view, and delete transactions.

### 4. Financial Reports

Users can generate:

* Monthly report
* Yearly report
* Savings calculation

### 5. Budget Management

Users can set monthly budgets for categories and receive warnings when exceeded.

### 6. Data Backup and Restore

Users can create a backup of the database and restore it when needed.

---

## How to Use

1. Run the program:

   ```
   python main.py
   ```

2. Register a new user.

3. Login to access the user menu.

4. Choose options from the menu:

   * Add Transaction
   * View Transactions
   * Delete Transaction
   * Generate Reports
   * Set Budget
   * Backup / Restore Data
